# 餐客厅 · 理想入住全景

基于前一版 `renders/20261108/interior-styled.blend` 渲染，保留原墙门、承重墙、U形抱墙端吧台、餐岛、沙发和主要家具位置。

新增灰绿与暖灰亚麻靠垫、原墙上的简洁挂画、阅读灯、纤细绿植、两人餐具与茶几上的书和咖啡。主要用于感受整体入住氛围；净尺寸、灯具与软装选择仍为概念方案，窗外仅作采光示意。

- `whole-living-dining.png`：2560×1440 全景。
- `ideal-living.blend`：可编辑的最终渲染场景。
- `hero_render.py`：可重建的场景与机位脚本。
- `render-manifest.json`：渲染机位和来源。

使用 Blender 4.5 LTS 或兼容版本运行脚本生成主图；`-- --draft` 可生成两个低分辨率取景草图。所有视角使用同一场景；墙体完整可见，没有为取景移墙或隐藏承重墙。
