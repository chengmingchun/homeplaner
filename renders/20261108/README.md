# 餐客厅室内效果图

四张图片由当前户型 Blender 模型通过 Cycles 渲染，保持镜像方位、两卫、门洞、厨房与书房间完整承重墙、餐岛及 U 形抱墙端吧台的关系。

- 01-living-to-kitchen.png：从客厅看餐岛、吧台、厨房和书房。
- 02-wall-wrap-counter.png：U 形台面包住完整墙端的近景。
- 03-study-to-living.png：从书房、桌游区回望客餐厅。
- 04-dining-and-living.png：餐岛、柔软 L 型沙发与南向露台。
- interior_render.py：材质、灯光、细部和机位的可重建脚本。
- render-manifest.json：源模型、机位和渲染信息。

生成时补充了地板、顶面、灯具、柜门、油烟机、水槽、门套、隔断顶轨、布艺和少量生活物件；将冰箱移离原概念摆位与隔墙相交的位置。这些属于方案深化，不代表已完成现场核尺或设备适配验证。

所有图共用一个场景，没有为某个机位隐藏承重墙或挪动房间。窗外为中性采光背景，不代表实际小区景观。单位为米，2000×1250 像素，普通室内摄影焦距，非鱼眼。墙高与净尺寸仍为原模型假设。

Blender 4.5 LTS 或兼容版本中运行本目录脚本即可重建；需要仓库中的 models/home-21101.blend。默认输出四张完整图片，`-- --draft` 可输出低分辨率草图，`-- --shot 02-wall-wrap-counter` 可选择一个机位。
