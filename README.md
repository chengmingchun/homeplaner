# 家居装修规划工具

在线访问：https://chengmingchun.github.io/homeplaner/

基于单页 HTML 的交互式 3D 装修规划工具，支持手机与电脑。

## 使用

- 手机单指旋转，双指缩放、平移；点选家具后拖动调整位置。
- 电脑拖动旋转，滚轮缩放，Shift 加拖动平移。
- 可切换俯视、立体、低视角，调整家具与开放厨房方案。
- 家具方案保存在当前浏览器本地，不会自动同步到其他设备。可导出布局 JSON 和图片。

## 文件

- `index.html`：当前装修工具，按最后一次要求左右镜像。
- `index.backup.html`：本次手机适配和户型调整前的备份。
- `户型图.jpg`：原户型参考资料。
- `010f1356-526b-4268-8dae-a8ac1c3b3a63.png`：补充参考图片，保留原文件名。
- `.github/workflows/pages.yml`：推送 main 后自动发布 GitHub Pages。

## 更新

修改 `index.html` 或参考图片后推送到 main，在 Actions 中查看发布结果。

模型为装修概念示意，门洞和门扇开向、墙体及尺寸仍需以现场及正式交付图纸核实。

房间名默认关闭，六套材料风格使用下拉菜单选择；厨房方案改为下拉菜单，包含开放、半开放和原墙对照。删除比例尺与重复说明，修正第三卫及南边残墙。

## Blender 三维模型

在线入口：[打开模型](https://chengmingchun.github.io/homeplaner/model.html)。Blender 原文件、GLB、建模脚本与使用说明放在 `models/`。模型按最新方案更新：主卫比例收紧、洗衣机南移、北侧开放功能间、波浪形移动花箱。

这版没有实测净尺寸，不作为测绘或施工模型。北侧活动隔断仅为条件方案，厨房与书房之间承重墙保留。

2026-11-08：删除储物间外侧重复建模墙；咖啡台改为1.5×0.5m圆角薄石材台面；餐岛缩小底柜并移动座椅。重新校正书房、厨房与露台的概念占地比例。`models/area-reference.json` 保留参考面积差异，`native-validation.json` 记录物件尺寸与模型内通道检查；这些均不替代量房。
