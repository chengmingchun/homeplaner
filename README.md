# 2-21101 · 三维户型

在线查看：[打开三维模型](https://chengmingchun.github.io/homeplaner/)。手机和电脑均可访问，模型由 Blender 建立。

## 使用

- 手机单指旋转，双指缩放和平移；电脑拖动旋转、滚轮缩放、右键平移。
- 下拉切换全屋、俯视、客餐厅、北侧功能间、厨房及主卫。
- 支持完整墙高与低墙查看、北侧活动隔断开合，房间名默认不覆盖画面。

## 网站文件

- `index.html`：唯一的三维查看首页，无下载按钮及旧装修工具入口。
- `model.html`：兼容旧链接，自动跳转首页。
- `model-viewer.js`、`vendor/`：网页查看器与依赖，Three.js 许可证随文件保存。
- `models/`：Blender 原文件、网页 GLB、建模脚本、预览与验证说明。
- `.github/workflows/pages.yml`：推送 main 后发布三维首页及依赖；旧装修工具、方案页和备份 HTML 不再发布。

原户型图、早期方案与辅助资料留在仓库供追溯，网页以当前 Blender 模型为准。

## 模型说明

保留两卫、主卧朝客厅门、主卫南向门、厨房承重墙。包含开放工作娱乐间、圆角咖啡台、餐岛、柔软 L 型沙发及波浪形移动花箱。清除了储物间外侧重复墙，并调整书房、厨房与露台的概念占地比例。

没有实测净尺寸，不能用于测绘、下单或施工。家具按常用米制规格建立，墙体、门窗、通道和设备适配仍须结合正式交付图纸与现场复核。北侧活动隔断仅为条件方案；厨房承重墙坐标校准不代表移墙改造。`models/area-reference.json` 记录参考面积差异，`native-validation.json` 记录模型内尺寸检查。

南向接缝修订：补齐南向墙体漏接，门窗保留并以关闭玻璃和完整边框显示。咖啡台包住完整承重墙端；U 形让位槽位于家具台面，墙体没有开槽或开孔。
