# 2-21101 · 三维户型

[打开当前三维模型](https://chengmingchun.github.io/homeplaner/)。首页直接载入温润意式方案，手机和电脑均可查看。

- 手机单指旋转、双指缩放和平移。电脑拖动旋转、滚轮缩放、右键平移。
- 下拉切换全屋、俯视和局部视角。默认使用完整墙高，可切换低墙查看，也可独立开合厨房门与电竞间门。
- 「效果图与说明」内可查看同一版的岛台、电视墙隐形门、洗烘餐边柜、L 型厨房和各空间效果图。

## 当前模型

网页模型、Blender 文件和效果图位于 [models/island-layout](models/island-layout/)。厨房保留北窗和 L 型橱柜，承重墙厨房侧补浅柜。餐岛由备餐岛和低台组成。东南次卧门与电视柜饰面齐平。主卫外侧试排洗烘餐边柜，家政间按八百库收纳布置。

模型按原图两段总尺寸校准。北侧分隔和主卫东墙均为拟调整方案。原墙性质、防水、机位给排水与通风、局部净尺寸待现场复核。

原户型资料及早期方案仅留作建模来源和项目记录。GitHub Pages 只发布当前模型、同版效果图与查看器，旧页面地址会打开首页。
