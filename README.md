# 2-21101 · 三维户型

[打开当前三维模型](https://chengmingchun.github.io/homeplaner/)。首页直接载入意式岛台与双推拉门方案，手机和电脑均可查看。

- 手机单指旋转、双指缩放和平移。电脑拖动旋转、滚轮缩放、右键平移。
- 下拉切换全屋、俯视和局部视角。可独立开合厨房门与电竞间门。
- 「效果图与说明」内可查看同一版的岛台、双门关闭、L 型厨房、电竞间、主卧和家政间。

## 当前模型

网页模型、Blender 文件和效果图位于 [models/island-layout](models/island-layout/)。厨房北窗下设 L 型橱柜，洗衣机位于家政间。保留厨房承重墙，墙端采用浅褐色包柜。

模型按原图两段总尺寸校准。北侧分隔位置是拟调整方案，原墙性质、局部门窗及通道尺寸和家政间给排水待现场复核。

原户型资料及早期方案仅留作建模来源和项目记录。GitHub Pages 只发布当前模型、同版效果图与查看器，旧页面地址会打开首页。
