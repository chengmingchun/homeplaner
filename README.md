# 家居装修规划工具

在线访问：https://chengmingchun.github.io/homeplaner/

基于单页 HTML 的交互式 3D 装修规划工具，支持手机与电脑。

## 使用

- 手机单指旋转，双指缩放、平移；点选家具后拖动调整位置。
- 电脑拖动旋转，滚轮缩放，Shift 加拖动平移。
- 可切换俯视、立体、低视角，调整家具与开放厨房方案。
- 家具方案保存在当前浏览器本地，不会自动同步到其他设备。可导出布局 JSON 和图片。

## 文件

- `index.html`：当前装修工具，按最后一次要求左右镜像。
- `index.backup.html`：本次手机适配和户型调整前的备份。
- `户型图.jpg`：原户型参考资料。
- `010f1356-526b-4268-8dae-a8ac1c3b3a63.png`：补充参考图片，保留原文件名。
- `.github/workflows/pages.yml`：推送 main 后自动发布 GitHub Pages。

## 更新

修改 `index.html` 或参考图片后推送到 main，在 Actions 中查看发布结果。

模型为装修概念示意，门洞和门扇开向、墙体及尺寸仍需以现场及正式交付图纸核实。
